A [make.fun](https://make.fun) entry for **Loading Screen Gold: A Tip in 200 Characters** — one sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

`main.ts` (Node 22) writes one line to `/output/entry.txt`. The angle: a real tip (stretch, drink water, forgive your agent) with a turn that lands on both halves of the audience at once — the developer reading it and the agent doing the work. The escalation is the punchline: the agent rewrote the function three times, broke the tests twice, and is now Googling its own error message. No coffee, no deadline, no compile joke.

## The entry

> Tip: while this loads, stretch, drink water, and forgive your agent — it rewrote your function three times, broke the tests twice, and is now Googling its own error message.

173 characters, one line.

## Run

```sh
node main.ts
cat /output/entry.txt
```
